# MOVIES SQL ANALYSIS

## PROJECT OVERVIEW

SQL analysis project based on a movie dataset using queries to retrieve, filter, sort, group, and analyze movie data.

## DATABASE AND TABLE

- Database: SQL Database
- Table: MOVIES

## COLUMNS USED

- MOV_NAME
- ACT_NAME
- DIR_NAME
- LANG
- REL_YEAR

## SQL CONCEPTS

- SELECT
- DISTINCT
- WHERE
- AND / OR
- LIKE
- BETWEEN
- ORDER BY
- LIMIT
- COUNT
- COUNT(DISTINCT)
- GROUP BY
- HAVING
- SUBQUERIES

## ANALYSIS PERFORMED

- Movie details and specific columns
- Movies by release year
- Movies by actor and director
- Movies by language
- Movie sorting and filtering
- Movie count by language
- Movie count by actor
- Movie count by director
- Movie releases by year
- Highest movie releases by year
- Most active actors and directors
- Actors working across multiple languages
